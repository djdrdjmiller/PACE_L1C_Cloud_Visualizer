# Current scientific conventions

Audited 2026-10-19; molecular refinement updated 2026-10-26. Wavelength-dependent dry-air molecular anisotropy now enters both Rayleigh phase elements and optical depth consistently (Bates/Bodhaine). Existing boundaries and Stokes conventions are retained; molecular multiple scattering remains excluded. See ATMOSPHERE.md for constants, model-version replay changes and unverified SWIR refractivity extrapolation beyond 1690 nm. Source measurements/diagnostics remain TOA; authorized experimental map corrections are described separately below.

Observations remain uncorrected top-of-atmosphere quantities. Radiance is converted using π r² X / (F0 cos(solar zenith)); intensity and polarization use their own irradiance metadata. Nighttime or invalid irradiance is masked. Stokes rotation follows equation 6 of the [PACE L1C Technical Report](https://oceancolor.gsfc.nasa.gov/files/NASA_TM2024219027v12_Level_1C_Format.pdf). Canonical scattering Q/U are retained, while signed displays negate them. Polarized magnitude stays nonnegative. DoLP uses original radiance Q/U divided by positive original I. Display limits never clip these scientific fields.

OCI uses exactly one valid view at each bin. No averaging or substitution hides missing/ambiguous slots. Image band slices are materialized before full cubes; selected spectra read all bands only at the chosen bin. HARP2 channels come from wavelength/nominal-angle metadata, including shuffled channel tables and known singleton spectral axes. Geometry is per original bin/view. RGB chooses nearest sectors about a sparse-band anchor; reported angle spans are a display warning, not a scientific equivalence criterion.

Correspondence requires matching time/nadir metadata and complete shared-geolocation comparison (20 m engineering tolerance). Conflicting declared grid sources are rejected. OCI V3's missing grid-source attribute is reported explicitly; identical full geolocation can establish correspondence without inventing that attribute.

The default Plate Carrée view follows the [Help Hub approach](https://nasa.github.io/oceandata-notebooks/notebooks/harp2/harp2_basic_visualizations.html): geolocated original cells, shared crop from valid HARP2 RGB support, and optional offline coastlines. Region-centered LAEA is also available. Geographic half-bin boundaries are inferred from adjacent centers; holes/disconnected polygons are rejected. Raster preview pixels carry original-cell IDs generated by the same polygons. No nearest-center selection bridges swath gaps. Scientific arrays are never regridded.

Native display uses the original source swath and geographic contours. Validation independently reconstructs NASA's transverse sin-angle and radius-dependent geocentric-latitude equations from each row's nadir and endpoint geolocation, then checks all other centers. The [NASA source](https://git.smce.nasa.gov/oel/ocssw/-/blob/develop/src/l1cgen/hawkeye_methods.cpp) is inspected as reference, not executed or redistributed. Acceptance tolerances are 20 m center error and 100 m row-spacing deviation. This recovers the published grid; it does not regenerate orbit telemetry. Failed validation remains explicitly labeled unverified. Geographic display does not depend on this reconstruction.

The angular inspector retains all source samples in its API, while the plotted panel shows only the metadata-derived hyperangular band (664.564 nm in the benchmark). Branch 1 precedes the scattering-angle turning point in original view order, branch 2 follows it. A descending nominal-angle fallback handles shuffled metadata. These labels are exploratory until operational branch logic is verified. Observations are points, never connecting lines.

At the user's later explicit request, an optional cloudbow stored-fit curve was added. GPC registration checks time, declared grid, nadir, and full geolocation. Only zero-quality-flag retrievals with finite C/B/A coefficients and in-range microphysics are used. The supplied Mie LUT is bilinearly interpolated in log radius/log variance following the supplied unweighted reference; native dense angular samples are evaluated directly. The full model A P21 + B(cos²θ − 1) + C receives the same negative display transform as scattering-plane Q. It is compared only on scattering-angle/−Q axes.

This overlay is an **experimental stored-coefficient reconstruction**, not independently verified operational reproduction. The public GPC V4.0 product differs from the notebook's development L2CLD. Exact operational LUT identity, spectral response, irradiance/distance normalization and selected branch remain unresolved. Missing/failed retrievals preserve the selected bin and show a reason. The separately authorized fixed-mode RFT comparison is documented in [RFT.md](RFT.md); it reuses original same-bin cloudbow C/B/A without any new fitting, preserving reported modes and using normalized number-fraction*Csca weights. Full mode responses include the common A/B/C background; named model residuals use branch 1 only. The authorized experimental atmospheric prototype is documented in [ATMOSPHERE.md](ATMOSPHERE.md) and its development is currently parked.


Experimental Rayleigh map correction subtracts modeled molecular I/Q/U with the documented reference-plane and irradiance conversions before deriving magnitude/DoLP. Rayleigh applies to classified land and water using the unchanged trial equations and cloud/MERRA-2 pressure; unclassified surface bins bypass correction. Missing classified corrections remain missing, with no TOA substitution. Legacy transmission is water-only; new land correction never divides by that table. Historical water-only Rayleigh recipes remain replayable with `rayleigh_land=false`; new/browser recipes use true. Angular observations, spectra, model comparisons and residuals remain TOA even when maps are corrected. This prototype is not independently validated full atmospheric correction. The retired 1050 hPa surface transmission extension is not available through current validated recipes; its removal does not change the analytical Rayleigh model's separate pressure bounds. See [ATMOSPHERE.md](ATMOSPHERE.md).

Current RFT display update (2026-10-26): RFT refl. and RFT component use the authorized optically thick single-scattering model without A/B/C, actual source geometry and omega=1; RFT P12/cloudbow retain stored A/B/C. Residuals are model minus observed in displayed −Q. Preserve explicit LUT phase-unit normalization and its unresolved P11-integral verification; see [RFT.md](RFT.md). This supersedes earlier all-RFT-A/B/C wording.

Liquid-index workspace and maps (2026-10-27): observed TOA red-band baselines/contrast, default discrete mean and user-requested trapezoidal angular mean, with a fixed baseline reference at 135° following original-paper Figure 4. Signed −Q and magnitude alternatives remain distinct. See [LIQUID_INDEX.md](LIQUID_INDEX.md); operational sample/normalization parity is unresolved, and map coverage is not forced to GPC selection.

OCI storage-layout compatibility (2026-11-05): older two-view files use view-indexed tilt metadata; a newer observed OCI V3 layout has one original observation slot and `sensor_view_angle[bins_along_track]` (the row's tilt). The reader preserves that single view and complete row profile, reports no invented global nominal angle, and exposes the selected row's actual tilt in OCI diagnostics. Reflectance still uses original per-bin solar geometry/counts/irradiance. Row-indexed tilt is accepted only for OCI with exactly one view and matching row count; ambiguous layouts reject. This is metadata-layout support, not regridding or a new physical model.
