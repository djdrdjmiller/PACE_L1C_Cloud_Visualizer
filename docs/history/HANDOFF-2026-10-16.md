## Release 1 requirements

- The five cases are a primary scientific scene, multi-angle coverage, OCI tilt transition, dateline crossing, and high latitude. Inspect candidate content; do not equate a catalog bounding-box match with a verified case. Mark missing cases explicitly and retain candidates/reasons for reproducibility.

- Normalize each instrument into adapters retaining original spatial indices, views, wavelengths, nominal angles, per-bin geometry, radiances, uncertainties/quality where supplied, units, product identity, and processing metadata. Do not invent official sector names. Support actual dimension permutations and known singleton band axes.
- Validate matching time/grid/source metadata and geolocation. Accept a direct shared-bin mapping only when verified. Release 1 may reject an incompatible pair with an actionable explanation; do not silently resample scientific arrays to manufacture alignment. Map preview reprojection is separate from source-bin correspondence.

### Maps and diagnostics

- Show OCI total-reflectance RGB/false color, HARP2 total-reflectance RGB/single band, and a third HARP2 map switchable between polarized-magnitude RGB, DoLP RGB, and signed single-band scattering-plane reflectance. All are uncorrected TOA in release 1.
- OCI default targets are 645/555/443 nm. Select measured channels from metadata and expose actual centers. The 645 nm red choice is explicit to avoid the near-650/660 bright-target saturation concern. Include all available L1C wavelengths in selected-bin spectra, with a radiance toggle.
- HARP2 true-color uses approximately ten green-sector anchors and nearest visible-channel matches. Advanced controls allow manual source sectors. False-color presets anchor to a participating sparse band. Report actual nominal angles and maximum channel-angle span; begin with a configurable 5-degree warning, a display default rather than a scientific equivalence claim.
- Use all available per-wavelength views for selected-bin diagnostics, including all red views. Show polarized magnitude, signed scattering-plane Q/U, and DoLP as selectable quantities; support scattering-angle and nominal-sector-angle axes. Apply the user's preferred negative display convention to cloudbow comparisons consistently and explicitly.
- Preserve native 5.2 km sampling. Provide validated native SOCEA plus geographic views, starting with Plate Carrée and region-centered Lambert azimuthal equal area. Validate native projection against actual geolocation and NASA definitions before labeling it SOCEA. A mere row/column image is not sufficient evidence of a geographically correct native map.
- One scene state owns selected original bin, extent/crop, projection, and rendering recipe. Clicking any of three maps updates all markers and both diagnostics. HARP2 maps share source channels/sectors; quantity-specific enhancement remains independent. Bin selection persists through view/mode changes and missing observations.
- Geographic screen-to-bin selection must use projected source-cell geometry or a verified inverse mapping. Downsampled previews must not select downsampled scientific pixels. Handle dateline splitting, swath fill, and crop boundaries without bridging unrelated cells.
- Provide fixed comparison enhancement and a saved adjustable beauty preset. Preserve raw scientific values, including reflectances above one and signed negatives. DoLP display range defaults to 0–1; scientific values/quality remain available independently of display clipping. Scalar signed maps use a diverging zero-centered scale.

### Figure exports

Render PNG and PDF from Python scientific arrays and the same versioned scene recipe used for preview. Support one map, multiple maps, and maps with diagnostics. Export physical dimensions, DPI, fonts, geographic annotations, legends/channel labels, selected-bin markers, and optional titles. Use raster imagery and vector text/axes in PDF where practical; do not export a dashboard screenshot.

Starting presets: paper width 180 mm at 300 DPI, presentation aspect ratio 16:9 at an editable size. Permit dimension/DPI changes. Save a JSON recipe with input identities/hashes, source wavelengths/sectors, geometry/projection, crop, enhancement, selection, masks, and software version. Record choices needed to reproduce the figure; omit credentials and private account state.

## Architecture and interfaces

Use a Python package with scientific adapters and a local FastAPI service. Build a modest TypeScript/Vite browser frontend with Plotly.js diagnostic plots and a canvas/SVG map surface receiving server-rendered projected layers. Serve the built frontend locally from the same service. This stack is the handoff default; change it only for a demonstrated limitation while preserving the agreed Python-library/browser split.

Keep modules separated by responsibility: readers/normalization, scene matching/selection, radiometry/polarimetry, projection/rendering, acquisition/cache, recipes/exports, and HTTP orchestration. Notebooks call the library directly rather than the UI or server.

Minimum interface capabilities:

| Operation | Contract |
|---|---|
| Load/list scenes | Open explicit local files or a manifest pair; report metadata, validation status, available source channels/views, and extents |
| Render preview | Accept a scene recipe and preview size; return projected image layers plus the mapping needed to identify original bins |
| Select bin | Accept scene identity and original row/column or verified map hit; return OCI spectra and all HARP2 angular samples with geometry, masks, and quantities |
| Export figure | Accept the same recipe plus layout/dimensions/DPI; return PNG/PDF and recipe artifacts |
| Acquisition CLI | Discover, download, inspect, and list cache/manifests independently of the dashboard |

Choose concrete endpoint names and storage formats consistently in code; the capability boundaries above are the contract. Give recipes and manifests a schema version. Preserve null/missing values explicitly. Reject invalid indices, unsupported bands, unmatched pairs, and unavailable files with useful errors. Abort superseded rendering requests or discard stale results so an earlier view cannot overwrite a newer selection. Cache by source identity and scientific/render settings, not by filename alone.

Use the mockup as a workflow guide. Default to Analysis desk; responsive widths stack maps and controls without losing capabilities. Figure studio informs export composition. Replace schematic maps and charts completely. Optional controls should reflect actual capabilities; no enabled correction or fit controls before their implementation/verification.

## Approved later science

RFT model: F(theta) = A [w0 P12_0(theta) + w1 P12_1(theta)] + B [cos(theta)^2 - 1] + C. Hold original mode microphysics/weights fixed and fit one shared A/B/C, using the base unweighted reference first. Any opposite-branch fit is exploratory. Plot the user's negative display sign consistently.

Total-reflectance correction: mu_eff = mu0 mu / (mu0 + mu); rho_corrected = rho_TOA / T_effective, with no extra squaring. Use per-bin/view geometry, nearest pressure grid entry and bilinear water/cosine interpolation, strict missing/out-of-range rejection, exact metadata-referenced PROFILE/MET provenance, and separate corrected fields. OCI RGB temporarily shares the 0.64 transmission proxy; HARP2 shorter-band proxy correction is future/approximate. Other band mappings must be explicit. Preserve all uncorrected polarimetry and do not import the separate reflectance-ratio normalization.

POLDER/3MI-inspired polarized gas/Rayleigh correction is research only. Gas correction and removal of additive molecular scattering are distinct; model/subtract Q/U in a common frame before taking magnitude. Current scope deliberately retains TOA polarized imagery and fitting data.
